Frequency response functions

Receptance H = 1/(k − mΩ² + jcΩ) · Mobility Y = jΩ·H · Inertance A = −Ω²·H · Dynamic amplification factor Γ₀ = k|H| = 1/√((1−r²)²+(2ζr)²), with r = Ω/ωn and Ω = 2πf. Dashed line: natural frequency fn.

Experimental values

Each value is plotted as a magenta square on the four plots above (only if f ≤ 3fn). Conversion: Ω = 2πf, F₀ = ẊF·√((k/Ω)² + c²) (force transmitted to the mass through the spring and damper), inertance A = 9.80665·Ẍ/F₀ (Ẍ in g), mobility Y = A/Ω, receptance H = A/Ω², Γ₀ = kH. They use the current m, k and c, so they update if you change the system.
